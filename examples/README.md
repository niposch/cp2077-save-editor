# Example saves

Saves the web version offers under "Try an example save", so visitors can try the editor
without their own save. They're copied into the website build (`dist/examples/`) but left out of
the desktop app. The UI reads the list from [`index.json`](index.json).

**These files are not covered by the repository's MIT license.** They belong to their authors and
are redistributed here under the terms their authors published, with credit.

| folder | save | author | source | patch |
|---|---|---|---|---|
| `ManualSave-818` | Nocturne Op55N1 (Nomad, level 50) | **Lix** (Lix7PTE on Nexus Mods) | [Nexus Mods mod 15643](https://www.nexusmods.com/cyberpunk2077/mods/15643) | 2.31 |

The author's permissions for `ManualSave-818` (Nexus Mods, Permissions and credits) allow
uploading the file to other sites with credit to the creator. The files are unmodified copies of
the save folder from the published archive (`sav.dat`, `metadata.9.json`, `screenshot.png`).

## Adding an example

1. Only add saves you made yourself, or whose author permits redistribution. Credit them.
2. Put the save folder here (`<folder>/sav.dat`, `metadata.9.json`, `screenshot.png`).
3. Add an entry to `index.json` and a row to the table above.
